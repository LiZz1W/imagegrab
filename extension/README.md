# 图提取 ImageGrab 安装与使用说明

## 安装

1. 解压 `ImageGrab-1.0.0.zip` 到本地任意文件夹（文件夹内应直接看到 `manifest.json`）。
2. 打开 Chrome 或 Edge，在地址栏输入 `chrome://extensions` 并回车。
3. 打开页面右上角的「开发者模式」。
4. 点击左上角「加载已解压的扩展程序」，选择解压后的 `ImageGrab-1.0.0` 文件夹。
5. 安装完成后，刷新已经打开的商品详情页。

## 使用

1. 打开淘宝、天猫、京东、拼多多的商品详情页。
2. 页面右下角会出现「获取图片」按钮，点击它。
3. 扩展会打开一个新的图片画廊，展示扫描到的全部商品图。
4. 勾选需要的图片，点击「下载选中 PNG」逐张保存，或点击「打包 ZIP」一次下载全部。
5. 图片统一转换为 PNG，命名为 `商品图_001.png`、`商品图_002.png`……

## 说明

- 仅支持桌面版 Chromium 内核浏览器（Chrome、Edge）。
- 图片在本地完成扫描与格式转换，不会上传到任何服务器。
- 如某个店铺的图片启用了防盗链，个别图片可能下载失败，画廊会给出失败数量提示。
- 请遵守各电商平台的使用规则与图片版权，仅将下载的图片用于个人学习与素材整理。
