为什么需要图提取

商品图分散在各处，
下载起来总是很麻烦

做素材整理、竞品分析或二次创作时，一张张右键保存既费时又容易遗漏。图提取把整个详情页的图片找出来，集中交给你。

图片太分散

主图、详情长图、SKU 缩略图、背景图散落在页面不同位置，肉眼很难找全。

无法批量保存

几十张图片只能一张张右键另存，重复操作多，文件名还会乱成一片。

格式不统一

JPG、WebP、PNG 混在一起，后续还要逐个转换格式、改写文件名。

图提取的做法

扫描、过滤、预览、下载，四步一次完成

兼容普通图片、srcset 响应式图、常见懒加载属性和 CSS 背景图，自动过滤图标与小尺寸占位图，统一转换为 PNG 并按「商品图_001.png」规则编号保存。

核心功能

为「收集商品图」这件事
做减法

不注册、不上传、不打扰。打开商品页，点一下，剩下的交给图提取。

一键提取

自动扫描页面所有商品图，兼容 srcset、data-src 等懒加载写法，不用手动往下拖。

智能过滤

自动排除图标、logo、1×1 像素和小于 100×100 的占位图，只留下真正有用的商品图。

集中预览

在新标签页用网格展示全部图片，每张都带尺寸信息，点开即可查看大图。

自由勾选

默认全选，支持一键反选。只想要主图？取消勾选详情图就好，选择更精准。

统一 PNG

JPG、WebP 自动通过 canvas 转换为 PNG，文件名按「商品图_001.png」补零编号。

批量下载

逐张保存或一键打包 ZIP，实时显示进度与结果，几十张图也能一次带走。

安装步骤

四步装好，
一分钟开始使用

图提取是免安装商店的本地扩展，下载压缩包后按下面的步骤加载即可。支持 Chrome 与 Edge。

  1. 01

    下载并解压插件

    点击「下载插件」获取 ImageGrab-1.0.0.zip，解压到本地文件夹。

  2. 02

    打开扩展管理页

    在 Chrome 地址栏输入 chrome://extensions 并回车。

  3. 03

    开启开发者模式

    点击右上角的「开发者模式」开关，让它变成蓝色开启状态。

  4. 04

    加载已解压的扩展程序

    点击左上角按钮，选择解压后包含 manifest.json 的 ImageGrab-1.0.0 文件夹。
